🎬 Movie Listing and Rating Website

This is a task from SPCL Infotech Services Pvt.Ltd. to design and develop a functional and responsive Movie Listing And Rating Website. This website is going to display essential movie details like as title, genre, release year, and a rating system. Users should be able to view the list of movies, see 
details, and rate them. This project is based on UI/UX design, interacvity, and the ability to handle movie data efficiently.

📌 Project Overview

The Movie Listing and Rating Website is a web application that allows users to search, view, and explore movies along with their ratings, posters, and basic details. The website fetches movie data from an external movie API and displays it in a user-friendly interface.

🚀 Features

- Search movies by title
- Display movie posters
- Show movie details such as title, year, genre, and ratings
- Responsive movie card layout
- Simple and clean user interface
- API-based dynamic movie data

🛠️ Technologies Used

- HTML5 – Structure of the website
- CSS3 – Styling and layout
- JavaScript – Functionality and API integration
- Movie API (OMDb) – Fetching movie data

⚙️ How It Works

1. The user enters a movie name in the search bar.
2. JavaScript sends a request to the movie API.
3. The API returns movie data including posters and ratings.
4. The website dynamically displays the movies in card format.
